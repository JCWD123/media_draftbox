我先承认：这篇文章大概率没有“免费薅GPT”“省Token教程”“一键做短剧”好看。

数学天然不适合公众号。没有立刻能抄走的提示词，没有今晚就能部署的项目，也没有“普通人月入10万”的爽点。

所以国内很多报道最省事的办法，就是把“菲尔兹奖”四个字搬出来——AI又把数学家干掉了，AI又要抢奖了。

但我觉得，那反而把这件事真正有意思的部分遮住了。

这一次真正值得盯住的，不是AI会不会拿奖，而是OpenAI第一次把“发现—写证明—机器验收”摆成了一条完整链路。

01先别管数学：普通人最该看懂的，其实是三个数字
10横跨数学与理论计算机科学的十项新结果
2498月1日发布的原始手稿页数；8月6日更新版为253页
≈ $2KOpenAI称“找到这些解法”的Token按Sol API价折算成本

8月1日，OpenAI公开了一份很不“产品发布会”的东西：没有跑分表，没有摄影样片，没有新的聊天界面，而是一整套数学与理论计算机科学成果。

十项结果来自其下一代模型家族Astra的一个内部版本，覆盖高维球堆积、编码理论、群论、算术电路复杂度、量子复杂性、格密码和极值组合等方向。

里面有三项尤其适合大众理解：多色Ramsey数解决了Erdős问题183；极值图论部分解决了Erdős问题146与180。

最容易被忽略的一句，是OpenAI写在公告里的成本描述：找到这些解法所需的Token，如果按Sol API价格折算，大约2000美元。
注意：这不等于“花2000美元就能买10个数学突破”。它不是训练成本、人工成本、失败实验成本和研发成本的总和。准确的说法只是：OpenAI称，产生这些成功解法所需的Token，按Sol API价格折算约2000美元。

但即使加上这个限定，它仍然是一个很值得咀嚼的信号。

因为我们以前谈AI成本，通常是在算：写一段代码多少钱，生成一张图多少钱，客服一次对话多少钱。

现在，同一套“Token经济学”，第一次被摆到了前沿知识生产的桌子上。

03真正重磅的不是“答案”，而是OpenAI给每个答案都配了一张验收单

大模型做数学一直有一个致命问题：它太会把错误写得像真的。

自然语言证明越长，人越难逐行检查。一个看起来漂亮的推导，中间只要偷换一次条件，整栋楼都可能是歪的。

这也是为什么这次的GitHub仓库 openai/ten-proofs 比249页论文更值得看。

里面不是宣传稿，而是十份用Lean 4写的形式化证明。

这更像软件工程里的“代码 + 自动化测试”，而不是“作者说自己测试过了”。

拿大白话说：

以前一篇数学论文摆在你面前，你最终还是得信任作者、审稿人和同行。

现在，AI把一个额外的东西交出来了：你可以在相同的软件环境里重新跑一遍，让证明助手自己查。

AI最值得关注的变化，不是它开始“像数学家一样说话”，而是它开始交付可以被独立机器检查的工作产品。

当然，这里必须踩一下刹车：Lean通过，证明的是“形式化后的命题可以由这些前提推出”。至于形式化命题是否准确表达了原始数学问题，仍然需要数学家审阅。

但这已经比“相信模型没幻觉”前进了非常大的一步。

04数学看不懂没关系，我们只玩一个6个人的小游戏

十项结果里，我最想拿出来讲的，是Erdős问题183。

不是因为它最“高大上”，而是因为它的起点，小学生都能理解。

想象有6个人。任意两个人之间只有两种关系：朋友，或者陌生人。我们把朋友连成蓝线，陌生人连成红线。

无论你怎么连，总能找到三个人，他们两两全是朋友，或者两两全是陌生人。

这里插入：Ramsey 6人随机涂色 GIF / 截图

建议录制 5–8 秒：连续点击“重新随机涂色”3次，每次自动加粗一个同色三角形。

这就是Ramsey理论最迷人的地方：

表面上所有关系都可以乱涂，但当系统足够大时，混乱里会被迫出现结构。

两种颜色时，“6个人”就够了。

那如果不是两种颜色，而是 k种颜色 呢？

05从6个人到“宇宙爆炸”：Erdős真正问的是，颜色变多后这个数会长多快

把“朋友/陌生人”推广成k种颜色。

我们要找的，是一个最小人数：只要人数达到它，不管你如何用k种颜色给所有连线涂色，都必然出现一个同色三角形。

这个数叫多色三角Ramsey数，记作 Rk(3)。

过去已知的下界大致还是“固定底数的指数增长”。真正悬着的问题是：

它会不会比任何固定底数的指数函数长得都快？

Rk(3) ≥ [ c · k1/3 / log k ]kc 为某个绝对正常数；这是OpenAI当前更新版手稿给出的表述。

看不懂公式也完全没关系。

只看中括号里面：随着k变大，底数自己也在变大，然后整个底数还要再做k次方。

普通指数是 2k、10k——底数固定。

这里却像“底数也踩着油门，指数还同时踩着油门”。

所以它的k次方根不会停在某个常数，而会一路趋向无穷。这就是“超指数”最直观的意思。

OpenAI公布的当前Lean文件 MulticolorTriangleRamsey.lean 有3053行、约123KB。

123KB当然不能告诉普通人证明为什么漂亮，但它提供了另一种价值：这不是“AI声称自己证出来了”，而是一份可以拿去重新构建和检查的形式化证书。

06所以，AI是不是已经“配拿菲尔兹奖”了？这个问题其实问歪了

更容易传播的问题

AI是不是超过数学家了？
这够不够菲尔兹奖？
人类数学家是不是失业了？

真正值得追的问题

研究产出能不能规模化？
验证成本能不能大幅下降？
机器能否持续产生可审计的新知识？

“菲尔兹奖”当然是很好的流量按钮。

但把十项成果简单换算成“相当于几个菲尔兹奖”，本质上是传播学，不是数学判断。

不同问题的分量不一样；一个Erdős问题的编号，也不自动等于“顶刊级成果”。数学界仍然需要判断新颖性、意义、形式化是否忠实，以及这些方法能否产生后续研究。

而且OpenAI自己在公告里也把态度写得很克制：它希望数学共同体深入审阅这些结果，并明确承担手稿与Lean形式化的正确性责任。

真正变化的不是“AI也有资格进天才排行榜”，而是科学研究开始出现一种以前没有过的工程形态：答案可以生成，证明可以形式化，验收可以自动化。
07一个不做数学的普通人，为什么应该关心这件事？

如果你既不是数学家，也不准备研究Ramsey数，我觉得这件事仍然有三个很现实的含义。

1
AI的价值正在从“生产内容”，继续往“生产知识”迁移写文案、写代码、画图，是在已知空间里组合；前沿研究的门槛，是能不能真的推进一个原本没有答案的问题。
2
未来最贵的不是生成，而是“怎么验收”代码有测试，数学有Lean。医疗、法律、工程领域真正能规模化的AI，也一定需要各自的可验证机制。
3
人的价值会越来越往“定义问题”移动当机器越来越擅长推导，稀缺的会变成：什么问题值得算、什么约束不能丢、什么结果真的有意义。

这可能也是这条新闻最值得普通开发者留意的地方。

今天我们还在比较模型写代码谁快10%，Token谁便宜20%。

但更远一点看，真正拉开差距的也许不是“谁能多吐一万行代码”，而是谁能把一个模糊问题变成可验证的任务，再让模型持续交付。

结语：最重要的不是AI证明了什么，而是“正确”开始被产品化

过去我们担心大模型最大的理由，是它会一本正经地胡说八道。

所以这次OpenAI真正有分量的一张牌，不是“我们模型很聪明”。

而是：我把证明给你，把机器证书也给你。你不必相信我，你可以自己验。

这让我想到一个可能比“AI会不会替代数学家”更重要的问题：

如果未来越来越多领域都能建立这种机器可验收的闭环，那么AI真正进入产业和科研深水区的标志，或许根本不是模型又涨了多少分。

而是它开始学会连同“为什么它是对的”一起交付。

到那时，最稀缺的能力也许不是写出答案。

而是提出一个值得回答的问题，并准确地定义——什么才算答对。
