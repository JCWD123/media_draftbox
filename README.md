# DraftBox

会学习的 AI 写作助手 - 公众号内容全流程

## 安装

### Linux / macOS
```bash
curl -fsSL https://raw.githubusercontent.com/JCWD123/media_draftbox/master/install.sh | bash
```

### Windows PowerShell
```powershell
irm https://raw.githubusercontent.com/JCWD123/media_draftbox/master/install.ps1 | iex
```

## 使用

```bash
# 启动
draftbox

# 模型配置
draftbox model

# 配置向导
draftbox setup
```

## 功能

- **18+ 主题**：集成 wewrite 引擎
- **npm 渲染**：markdown-it + highlight.js + katex + mermaid
- **语法检查**：LanguageTool API（20+语言）
- **图片搜索**：Unsplash + Pexels
- **模型配置**：34个提供商（类 hermes）
- **自进化 Skill**：内置后端
